可以，下面这版更简单，假设对方已经有：

```text
Windows
Python 3.9
PowerShell
项目代码
```

只缺 Python 包。

```text
MPE 项目简易运行手册
```

**1. 装包**

进入项目目录：

```powershell
cd C:\Users\你的用户名\Desktop\MPE\on-policy
```

创建并激活虚拟环境：

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

如果激活失败，执行：

```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\.venv\Scripts\Activate.ps1
```

安装依赖：

```powershell
python -m pip install --upgrade pip setuptools wheel
```

```powershell
python -m pip install --prefer-binary numpy==1.23.5 scipy==1.10.1 gym==0.17.2 cloudpickle==1.3.0 pyglet==1.5.0 six==1.16.0 imageio==2.31.6 matplotlib==3.7.5 seaborn==0.12.2
```

```powershell
python -m pip install --prefer-binary torch==1.13.1 tensorboardX==2.6.2.2 tensorboard==2.14.0 wandb==0.16.6 setproctitle==1.3.3 absl-py==1.4.0
```

```powershell
python -m pip install -e .
```

**2. 运行训练**

快速测试：

```powershell
python onpolicy\scripts\train\train_mpe.py `
  --env_name MPE `
  --scenario_name simple_spread `
  --num_agents 3 `
  --num_landmarks 3 `
  --algorithm_name mappo `
  --experiment_name test_100k `
  --seed 1 `
  --n_training_threads 1 `
  --n_rollout_threads 1 `
  --num_mini_batch 1 `
  --episode_length 25 `
  --num_env_steps 100000 `
  --ppo_epoch 1 `
  --lr 7e-4 `
  --critic_lr 7e-4 `
  --use_wandb `
  --user_name local `
  --log_interval 100 `
  --save_interval 1000
```

说明：这里的 `--use_wandb` 必须加，因为这个项目里它表示关闭 wandb，改用本地日志。

**3. 显示到本地网页**

训练结束后运行：

```powershell
tensorboard --logdir onpolicy\scripts\results\MPE\simple_spread\mappo\test_100k\run1\logs --host 127.0.0.1 --port 6006
```

然后浏览器打开：

```text
http://127.0.0.1:6006
```

就可以看到训练曲线。
